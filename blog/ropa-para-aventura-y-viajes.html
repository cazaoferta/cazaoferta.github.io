Ropa para aventura y viajes: qué llevar

Para viajar o salir a la montaña no necesitas una maleta enorme. Necesitas pocas piezas que sirvan para todo.

El sistema de capas

Una capa base que respire, una capa media que abrigue (fleece o suéter) y una capa exterior que corte el viento y la lluvia. Con eso aguantas casi cualquier clima.

Mochila

Para viajes cortos, una mochila de 25 a 35 litros basta. Busca correas acolchadas y un compartimiento para la laptop.

Telas que secan rápido

Nylon, poliéster técnico y merino secan rápido y pesan poco. Evita el algodón grueso si vas a pasar frío o lluvia.
